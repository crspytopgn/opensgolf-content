# Hawaii Resort (example scenario)

A hotel group gives you $250,000 and some Hawaiian coast. Open **18 holes**, have **40 members** and reach a **fun rating
of 50**, all by the end of 2005.

## Install

In the game: **System Functions → Preferences → Content packs → Find more…**, pick this pack, click **Download**, switch it
on and restart. Or copy this folder into your `packs` folder yourself (see the main README).

With a scenario installed, **Start New Game** asks whether you want a free game or a scenario. **Information → Scenario
Goals** shows how you are doing.

## How it works

`scenario.toml` picks the property (`hawaii`; any of the sixteen ids works: monterey, san-diego, rocky-mtns, las-vegas,
phoenix, hawaii, oahu, nova-scotia, northeast, carolina, ireland, scotland, wales, spain, florida, jamaica), the starting
money, the difficulty, the texts, and the goals. A goal can ask for `holes`, `cash`, `fun`, `skill`, `members` or a
`rank`, optionally `by_year`.

Tip: you can also make a scenario from a game you are playing. Save it and click **Export as scenario pack**.
