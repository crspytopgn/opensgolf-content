# gfx: the upscaled pictures go here

This folder is empty in the template. The pictures are made by the maker in tools/hd_mod_pack, from your own copy of SimGolf, and put here.

Each file goes at the path of the original, as a WebP at quality 95, at 4 times the original's size. For example, gfx/Interface/BuildPanel.webp replaces Interface/BuildPanel.pcx, and gfx/Flics/Trees/TreeMapleLarge.webp is the sprite sheet for Flics/Trees/TreeMapleLarge.flc.

Do not put the original game files, or the maker's reference pictures, in here. Run sgtool pack-check on this pack folder before you share it.
